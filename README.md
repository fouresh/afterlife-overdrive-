# Afterlife Overdrive

Пиксельная кооперативная roguelite для браузера: погибни в нашем мире, переродись в другом и
узнай, что такое **Overdrive**. Играется на телефоне в горизонтальной ориентации, до 4 игроков
вместе.

## Играть

**Ссылка на игру:** `https://afterlife-overdrive.<поддомен>.workers.dev` — появляется после
настройки Cloudflare ([инструкция для телефона](docs/SETUP_CLOUDFLARE.md)). Точный адрес:
главная страница репозитория → **Deployments** → **production**.

Совет: в браузере телефона выберите «Добавить на главный экран» — игра запустится как
приложение, на весь экран и без панели браузера.

### Сюжет

Глава 1 «Пробуждение»: вы очнулись на древнем алтаре в Шепчущем лесу. Ведунья Мира приводит вас
в Убежище под старой часовней. Пройдите лес, спасите торговца Сая и кузнеца Боргана из клеток
(они переедут в Убежище и откроют рынок и кузницу) и победите Хранителя склепа. Текущее задание
видно под именем героя; весь сюжет — на доске заданий.

### Управление

| Телефон                                                        | ПК                |
| -------------------------------------------------------------- | ----------------- |
| Левая половина экрана — джойстик (появляется под пальцем)      | WASD / стрелки    |
| Большая кнопка справа — атака (автоприцел по ближайшему врагу) | ЛКМ, прицел мышью |
| `»` — рывок (неуязвимость на время рывка)                      | Пробел / ПКМ      |
| Фиолетовые кнопки — артефакты 1 и 2                            | Q / E             |
| Колба — зелье, ладонь — действие                               | R / F             |
| ⏸ — пауза                                                      | Esc / P           |

### Позвать друзей

1. В Убежище нажмите кнопку **отряда** (два человечка, справа вверху) → **«Создать отряд»**.
2. Нажмите **«Пригласить друзей»** — телефон предложит отправить ссылку в мессенджер (или она
   скопируется). Можно просто продиктовать код из 5 букв.
3. Друг открывает ссылку → «Играть» → выбирает героя → он уже в вашем отряде. Или: кнопка
   отряда → «Войти по коду».
4. Лидер подходит к **порталу** → «Отправиться отрядом». Все переносятся в данж вместе.

До 4 игроков; обычные и хардкор-герои могут играть вместе. Добыча у каждого своя. Павшего
союзника можно поднять: подойдите и удерживайте «руку». На лестнице каждый сам решает —
глубже или домой с добычей. Если пропала связь, игра переподключится сама (до 45 секунд).

### Если что-то сломалось

Игра покажет экран ошибки — нажмите **«Скопировать отчёт»** и вставьте текст в сессию Claude.
Для отладки добавьте к адресу `?debug=1`: появится счётчик FPS и служебная информация.

## Разработка

Всё делается через GitHub Actions; локально (или в облачной сессии Claude):

```bash
pnpm install
pnpm dev      # http://localhost:5173
pnpm check    # линт, типы, тесты, сборка, бюджет бандла
pnpm e2e      # Playwright smoke в мобильной эмуляции (после pnpm build)
```
