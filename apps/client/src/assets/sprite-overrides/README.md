# Замена спрайтов PNG-файлами

Положите сюда `<id спрайта>.png` (например `crypt.floor.png`), и при следующей сборке игра
возьмёт его вместо пиксельной карты из `packages/content`. Код менять не нужно.

- Кадры анимации идут слева направо, каждый кадр ровно `w × h` пикселей из описания спрайта.
- Точка опоры (pivot) берётся из описания спрайта.
- Список id: `pnpm sprites` рисует все спрайты; id указан первым аргументом `sprite('id', …)`.
