# Замена спрайтов PNG-файлами

Положите сюда `<id спрайта>.png` (например `crypt.floor.png`), и при следующей сборке игра
возьмёт его вместо спрайта из `packages/content`. Код менять не нужно.

- Графика игры — HD: 2 текселя на пиксель мира (тайл 16×16 мира = 32×32 текселя). Рисуйте
  PNG в этом разрешении: кадр = размер спрайта из `pnpm sprites` (уже в текселях).
- Старые PNG вдвое меньшего размера тоже работают: игра увеличит их алгоритмом Scale2x.
- Кадры анимации идут слева направо, каждый кадр ровно одного размера.
- Точка опоры (pivot) берётся из описания спрайта.
- Список id: `pnpm sprites` рисует все спрайты; id — первый аргумент `hd('id', …)` или
  `sprite('id', …)`.
