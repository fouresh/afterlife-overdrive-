# Настройка Cloudflare (с телефона, ~10 минут)

Игра деплоится автоматически из GitHub Actions на **бесплатный** тариф Cloudflare Workers
(банковская карта не нужна). Руками нужно сделать только 4 вещи: зарегистрироваться, скопировать
Account ID, создать API-токен и положить два секрета в GitHub. Базу данных D1, поддомен
`workers.dev`, миграции и сам деплой workflow делает сам.

> Совет: открывайте ссылки в обычном мобильном браузере (Chrome/Safari). Если какой-то экран
> Cloudflare выглядит обрезанным — поверните телефон горизонтально или включите «Версия для ПК»
> в меню браузера.

---

## Шаг 1. Регистрация в Cloudflare

1. Откройте https://dash.cloudflare.com/sign-up
2. Введите e-mail и пароль → **Sign up**.
3. Подтвердите почту по ссылке из письма.
4. Если Cloudflare предлагает «добавить сайт/домен» или выбрать тариф — **пропустите** (Skip /
   «Explore on my own»). Домен не нужен.

## Шаг 2. Скопируйте Account ID

Самый простой способ на телефоне — из адресной строки:

1. Откройте https://dash.cloudflare.com/ (вы залогинены).
2. Нажмите на адресную строку. Адрес выглядит так:
   `https://dash.cloudflare.com/0123456789abcdef0123456789abcdef/home`
3. Длинная строка из **32 символов** (цифры и буквы a–f) между `dash.cloudflare.com/` и
   следующим `/` — это и есть **Account ID**. Скопируйте её в заметки.

Запасной способ: меню (☰) → **Workers & Pages** → пролистайте вниз до блока **Account details**
→ **Account ID** → **Click to copy**.

## Шаг 3. Откройте Workers & Pages один раз

Меню (☰) → **Compute (Workers)** / **Workers & Pages**. Если появится приветственный экран —
просто закройте его. Так у аккаунта появится поддомен `*.workers.dev` (скрипт деплоя тоже умеет
создать его сам, это страховка).

## Шаг 4. Создайте API-токен

1. Откройте https://dash.cloudflare.com/profile/api-tokens
2. Нажмите **Create Token**.
3. Напротив шаблона **Edit Cloudflare Workers** нажмите **Use template**.
4. В блоке **Permissions** нажмите **+ Add more** и добавьте строку:
   - `Account` → `D1` → `Edit`
5. Проверьте, что в списке есть (они уже есть в шаблоне):
   - `Account` → `Workers Scripts` → `Edit`
   - `Account` → `Account Settings` → `Read`
6. **Account Resources**: `Include` → ваш аккаунт.
7. **Zone Resources**: оставьте как есть (`All zones`) — шаблон этого требует, домен не нужен.
8. Внизу нажмите **Continue to summary** → **Create Token**.
9. Нажмите **Copy** и сохраните токен в заметки. **Cloudflare покажет его только один раз.**

## Шаг 5. Добавьте секреты в GitHub

1. Откройте https://github.com/fouresh/afterlife-overdrive-/settings/secrets/actions
   (или: репозиторий → ⋯ → **Settings** → **Secrets and variables** → **Actions**).
2. Нажмите **New repository secret**:
   - Name: `CLOUDFLARE_API_TOKEN`
   - Secret: токен из шага 4
   - **Add secret**
3. Ещё раз **New repository secret**:
   - Name: `CLOUDFLARE_ACCOUNT_ID`
   - Secret: Account ID из шага 2
   - **Add secret**

Имена нужно ввести **точно так**, большими буквами.

## Шаг 6. Запустите деплой

Любой из вариантов:

- **Смержите PR** в `main` — деплой запустится сам.
- Или откройте https://github.com/fouresh/afterlife-overdrive-/actions/workflows/ci.yml →
  **Run workflow** → ветка `main` → зелёная кнопка **Run workflow**.

Через 5–8 минут в запуске появится шаг **Deploy (Cloudflare)** с зелёной галочкой.

## Шаг 7. Где ссылка на игру

- На главной странице репозитория справа (или внизу на телефоне) блок **Deployments** →
  **production** → ссылка `https://afterlife-overdrive.<ваш-поддомен>.workers.dev`.
- Или в запуске Actions → **Summary** → «🚀 Продакшен: …».
- Для каждого PR есть превью: `https://afterlife-overdrive-preview.<ваш-поддомен>.workers.dev`
  (бот пишет ссылку комментарием в PR).

Откройте ссылку на телефоне → меню браузера → **Добавить на главный экран** — игра установится как
приложение и будет запускаться на весь экран.

## Если что-то пошло не так

Откройте упавший запуск в Actions → шаг **Deploy** → там будет понятное сообщение.

| Сообщение                                           | Что сделать                                                                              |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| «Секреты Cloudflare не настроены — деплой пропущен» | Это не ошибка: секретов ещё нет. Пройдите шаги 4–5.                                      |
| `Authentication error` / `10000`                    | Токен скопирован не полностью или без прав. Создайте новый (шаг 4) и обновите секрет.    |
| «Нет доступа к D1»                                  | У токена нет строки `D1 → Edit`. Отредактируйте токен на странице API Tokens → **Edit**. |
| «Не удалось создать поддомен workers.dev»           | Сделайте шаг 3 и перезапустите workflow (**Re-run all jobs**).                           |
| `Account ID` / `could not route`                    | Проверьте, что в секрете ровно 32 символа без пробелов.                                  |

Если непонятно — скопируйте текст ошибки из лога и вставьте в сессию Claude.

## Что бесплатно и какие лимиты

Workers Free: 100 000 запросов к API в день (статика игры не считается), Durable Objects:
100 000 запросов и 13 000 ГБ·с в день, D1: 5 млн чтений и 100 000 записей в день, 5 ГБ.
Лимиты сбрасываются в 03:00 по Москве. Расчёт бюджета — в `docs/ARCHITECTURE.md`.
