# Roadmap

Каждый этап = отдельный PR в `main` (зелёный CI, описание, чеклист проверки на телефоне).
PR мержит владелец; используйте **Create a merge commit** (не squash), чтобы следующие PR,
основанные на предыдущих ветках, не конфликтовали.

## M1 — Соло-забег (вертикальный срез) ✅ (ветка `m1-solo-run`)

- [x] Контент-схемы (zod) и валидация в тестах: оружие, броня, артефакты, аффиксы, враги,
      снаряды, биомы, шаблоны комнат; перекрёстные ссылки (спрайты, снаряды, призывы)
- [x] Генерация крипты: BSP → комнаты → остовное дерево по соседним листьям (+ петли) →
      коридоры A* шириной 2 → роли на реальном графе (старт → бой → ключ/запертая сокровищница
      → магазин → мини-босс → лестница/босс) → ASCII-шаблоны интерьеров → декор и спавны
- [x] Тест 1000 seed'ов: достижимость, нет запечатанных карманов, спавны на полу, двери проходимы
- [x] Боевые комнаты: двери закрываются, волны, зачистка, награды; ключ и запертая дверь
- [x] Оружие: меч, топор (дуга), кинжал (выпад), лук, арбалет (снаряд), посох (снаряд + удар
      вблизи); автоприцел; отражение вражеских снарядов ударом
- [x] Враги (6): скелет-воин, скелет-лучник, слизень, нетопырь, культист, призрак;
      мини-босс «Костяной рыцарь» и босс «Хранитель склепа» с фазами
- [x] Артефакты (9) из композиции эффектов: снаряд, область, рывок, бафф, лечение, щит, призыв
- [x] Лут: 5 редкостей, уровень, аффиксы, личный лут, детерминированные seed'ы предметов;
      сундуки, ключ, магазин (3 слота), зелья, золото
- [x] HUD: здоровье/щит, золото, зелья, ключи, этаж, кулдауны на кнопках, подсказка действия,
      полоса босса, миникарта с туманом войны, сумка/инвентарь
- [x] Смерть → итоги (добыча потеряна) → меню; между этажами «уйти или глубже»; победа над боссом
- [x] Звук: процедурные эффекты WebAudio (~30 звуков), разблокировка на iOS
- [x] Juice: hit-stop, тряска, вспышки, частицы, цифры урона, свечение снарядов, телеграфы
- [x] Тесты: боты проходят этажи и убивают босса; soak-тест; perf-guard тика
- [x] Playwright: меню → выбор оружия → данж → бой → убийство врага; тур по экранам

## M2 — Персонаж и хаб ✅ (ветка `m2-character-hub`)

- [x] Создатель персонажа: пол, имя (валидация + фильтр мата на клиенте и сервере), кожа,
      7 причёсок и цвет, глаза, цвета одежды, живое превью (стойка/бег), «Случайно»
- [x] Хардкор с предупреждением, значок ☠, отдельный склад/золото/материалы/контракты;
      до 6 живых героев, павшие — в «Зале памяти»
- [x] Интро: «Как вы погибли?» (5 вариантов → постоянный бонус) и текст перерождения
- [x] Хаб «Убежище» — ходьба, NPC (Мира, Борган, Сай), станции: склад/экипировка, кузница
      (улучшить, перековать, создать, разобрать), алхимик (зелья, эликсиры), рынок (товар дня,
      продажа с насыщением цен, материалы), статуя (уровни, характеристики, сброс), доска
      контрактов, портал (сложность: обычная/сложная/кошмар), Зал памяти
- [x] Прогрессия: опыт → уровни → 3 очка за уровень (Сила/Ловкость/Интеллект/Живучесть),
      уровень предметов от уровня героя и сложности
- [x] Анонимный аккаунт (токен устройства, на сервере — хеш), код восстановления
      (XXXX-XXXX-XXXX, хеш), облачные сохранения в D1 с ревизиями и разрешением конфликтов,
      кэш в IndexedDB, схема v2 и миграция профиля M1
- [x] Сервер: zod-валидация сохранений (границы против читов), rate limit, seed забега с
      сервера (таблица runs) — основа проверки происхождения лута
- [x] Тесты: операции аккаунта и экономики, миграция, API на настоящем SQLite (node:sqlite),
      e2e: создание героя → хаб → данж → убийство → итоги → склад
