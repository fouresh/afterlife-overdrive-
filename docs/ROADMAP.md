# Roadmap

Каждый этап = отдельный PR в `main` (зелёный CI, описание, чеклист проверки на телефоне).
PR мержит владелец; используйте **Create a merge commit** (не squash), чтобы следующие PR,
основанные на предыдущих ветках, не конфликтовали.

## M0 — Фундамент ✅ (ветка `m0-foundation`)

- [x] Монорепо pnpm: `packages/{shared,sim,procgen,content}`, `apps/{client,server}`
- [x] TypeScript strict, ESLint (запрет недетерминированного API в пакетах), Prettier, Vitest
- [x] Детерминированный RNG и тригонометрия, бинарный кодек, квантованный ввод
- [x] Пиксельные спрайты кодом: палитра, paper-doll (6 причёсок, 2 пола, броня), тайлсет крипты
- [x] Атлас текстур на canvas + замена PNG без кода
- [x] Рендер в низком разрешении с целочисленным апскейлом, чанки карты, свечение факелов
- [x] Sim: SoA-сущности, фиксированный шаг 30 Гц, движение, рывок, коллизии с тайлами
- [x] Плавающий джойстик + кнопки (атака, рывок, 2 артефакта, зелье, действие), клавиатура/мышь
- [x] `?debug=1` оверлей, экран ошибки с «Скопировать отчёт»
- [x] PWA: манифест, иконки из пиксель-арта, service worker, fullscreen + landscape
- [x] Worker: статика + `/api/health` + каркас Durable Object + D1-миграция
- [x] CI: lint, format, typecheck, unit, build, бюджет бандла, wrangler dry-run, Playwright smoke
- [x] Деплой: production (main) и preview (ветки), пропуск без секретов, ссылка превью в PR
- [x] Документация: CLAUDE.md, GDD, ARCHITECTURE, ROADMAP, DECISIONS, SETUP_CLOUDFLARE

## M1 — Соло-забег (вертикальный срез)

- [ ] Контент-схемы (zod) и валидация в тестах: оружие, артефакты, аффиксы, враги, биомы
- [ ] Генерация крипты: граф комнат (старт → бой → ключ/дверь → сокровищница/магазин →
      мини-босс → выход/босс), BSP-раскладка, ASCII-шаблоны, декор по правилам биома
- [ ] Тест 1000 seed'ов: достижимость, нет софтлоков, спавны на полу
- [ ] Боевые комнаты: закрытие дверей, волны, зачистка

- [ ] Враги (6): скелет-воин, скелет-лучник, слизень, летучая мышь, культист, призрак;
      мини-босс и босс крипты
- [ ] Артефакты (8) из композиции эффектов, 2 слота, перезарядки на кнопках
- [ ] Лут: редкость, уровень, аффиксы, личный лут; сундук, ключ, магазин, зелья, золото
- [ ] HUD: здоровье, золото, ключ, перезарядки, мини-карта
- [ ] Смерть → экран итогов → меню; между этажами «уйти или глубже»
- [ ] Звук: процедурные эффекты WebAudio, разблокировка на iOS
- [ ] Juice: hit-stop, тряска, вспышки, частицы, цифры урона
- [ ] Playwright: войти в данж и убить врага
