# Roadmap

Каждый этап = отдельный PR в `main` (зелёный CI, описание, чеклист проверки на телефоне).
PR мержит владелец; используйте **Create a merge commit** (не squash), чтобы следующие PR,
основанные на предыдущих ветках, не конфликтовали.

- [x] Тест 1000 seed'ов: достижимость, нет запечатанных карманов, спавны на полу, двери проходимы
- [x] Боевые комнаты: двери закрываются, волны, зачистка, награды; ключ и запертая дверь
- [x] Оружие: меч, топор (дуга), кинжал (выпад), лук, арбалет (снаряд), посох (снаряд + удар
      вблизи); автоприцел; отражение вражеских снарядов ударом
- [x] Враги (6): скелет-воин, скелет-лучник, слизень, нетопырь, культист, призрак;
      мини-босс «Костяной рыцарь» и босс «Хранитель склепа» с фазами
- [x] Артефакты (9) из композиции эффектов: снаряд, область, рывок, бафф, лечение, щит, призыв
- [x] Лут: 5 редкостей, уровень, аффиксы, личный лут, детерминированные seed'ы предметов;
      сундуки, ключ, магазин (3 слота), зелья, золото
- [x] HUD: здоровье/щит, золото, зелья, ключи, этаж, кулдауны на кнопках, подсказка действия,
      полоса босса, миникарта с туманом войны, сумка/инвентарь
- [x] Смерть → итоги (добыча потеряна) → меню; между этажами «уйти или глубже»; победа над боссом

## M3 — Мультиплеер ✅ (ветка `m3-multiplayer`)

- [x] Отряды до 4 героев: создать в хабе (открытый/закрытый), войти по коду из 5 символов, по
      ссылке `?room=CODE` (Web Share API или копирование), список открытых отрядов; лидер,
      исключение, передача лидерства, смешанные отряды обычных и хардкор-героев
- [x] Комната = Durable Object: лобби на Hibernation API (состояние в storage), забег —
      сервер-авторитет 30 Гц тем же `step()`; каталог комнат в D1 (`0003_rooms.sql`)
- [x] Бинарный протокол: изменения ввода (≤10 пакетов/с), дельта-снапшоты 15 Гц, полный
      снапшот при переподключении; JSON для лобби, этажей, инвентаря, итогов
- [x] Предсказание и реконсиляция своего героя (тот же код движения, сглаживание поправок),
      интерполяция остальных на 4 тика в прошлом, события в такт отрисовке
- [x] Переподключение при смене сети (место держится 45 с, баннер, повтор этажа и полный
      снапшот), неуязвимость отключившегося; потеря связи навсегда — исход «связь потеряна»
- [x] Кооп-правила: личный лут, сложность и HP врагов от числа игроков, поднятие павших
      союзников, голосование «глубже/домой» на лестнице, наблюдение после смерти, итоги с
      сервера; HUD союзников, союзники на миникарте
- [x] Тесты: зеркало мира по снапшотам побитно (и после переподключения), предсказание с
      задержкой и джиттером, правила кооператива, RoomCore (лобби, забег, голосование,
      переподключение, гибернация, мусорные пакеты), API комнат; e2e двумя «телефонами»
      против `wrangler dev`
- [ ] Позже: имена над головами союзников, адаптивная задержка интерполяции, чат-эмоции,
      серверная проверка предметов (с аукционом)
